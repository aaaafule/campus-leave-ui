# 还原笔记

记录每个尺寸是怎么量出来的、为什么这么改。所有数值都来自对截图/录屏的像素统计，
不是凭视觉估的。

## 1. 尺度换算

| 素材 | 尺寸 | 换算 |
|---|---|---|
| 录屏（第一页、第二页的齿带） | 720 宽 | ×0.5208 → 375 CSS |
| 手机截图 | 1216 宽 | ÷3.243 → 375 CSS |

所有 `px` 都是 375 设计宽下的 CSS 像素，手机上再用 `innerWidth / 375` 等比缩放。

## 2. 尺寸的测量方法

- **墨迹包围盒**：取元素区域，统计非背景色像素的 bbox，得到字宽/字高。
- **行剖面**：沿竖直方向统计某类像素的数量，用峰值定位块状元素（胶囊、按钮、分割线）。
- **颜色中位数**：对区域取中位数而不是均值，避免抗锯齿与 JPEG 噪点干扰。
- **接缝 MAD**：判断齿带平铺周期时，把左右边界差值的平均绝对误差算到最小，
  而不是用自相关——后者在周期性强纹理上容易给出倍数解。

## 3. 几个具体结论

### 时钟胶囊（第二页，横幅下方）

从 1216 宽截图反算（÷3.243）：

| 项 | 实测 | 说明 |
|---|---|---|
| 尺寸 | 157.3 × 13.9 CSS | 之前 18.5 高，是因为行高继承了 1.4 |
| 压暗 | 灰值 127 → alpha ≈ 0.50 | 之前用 .38，偏透 |
| 左右内边距 | 4.6 | — |
| 底边距齿带 | 1.2 | 之前 4，偏上 |

还有一个隐蔽的 bug：`.hero__clock` 用 `transform: translateX(-50%)` 居中，
但入场动画 `fadeUp` 的终帧写的是 `transform: none`，`animation-fill-mode: both`
会让这个 `none` 一直生效，把居中变换冲掉——胶囊就整体右移了半个宽度。
给胶囊单独一套 `clockIn` 关键帧（保留 translateX）才解决。

### 齿带（锯齿条）

- 高度恒为 31 px（720 素材）→ 16.1 CSS
- 周期：第一页 117 px，第二页 115 px（不同录屏略有差异），用接缝 MAD 判定
- 速度：约一个周期 / 秒，即 720 素材下 ≈115 px/s → 59.9 CSS px/s
- 实现：裁一个完整周期做 `background-repeat: repeat-x`，
  `background-size` 设成「周期 × 高度」，`@keyframes` 平移一个周期

### 时长徽章

规则照抄逆向时 PC 端的 `calcDuration`：

```
空 / 格式非法 / 结束 ≤ 开始  →  显示「—」
否则  →  X天X小时X分钟（0 的段省略，至少保留一项）
```

触发点：开始/结束任何变化（手打、选择器、跨页继承）以及页面加载。

## 4. 字体

真机是 PingFang SC / Noto Sans CJK，Windows 落到微软雅黑，同样 400 的笔画会明显更粗。
姓名处优先用系统自带的 **Microsoft YaHei Light**（`msyhl.ttc`），更接近手机端的字重。

验证方式：给每个可编辑元素造一个「同标签、同类名、去掉 contenteditable」的对照节点，
同分辨率对比**字形推进宽度**与 8 项 computed style——宽高一致才算字体没变。

## 5. 交互设计上的取舍

- **只覆盖有值的字段**：跨页继承时，上一页留空的项保留本页原值，
  否则继承成一片空白，而那几个位置在下一页不可编辑，救不回来。
- **每次打开重置**：不用 localStorage，刷新即回空白模板；
  跨页传递用 sessionStorage 且读完即删——既是「一次性」，又不会在关闭程序后残留。
- **时间只允许选择器输入**：禁掉键盘手打，避免出现 `2026年3月` 这类脏格式。
- **编辑态与展示态共用一套 CSS**：`.ed` 里不写任何 `font-*` / `padding` / `line-height`，
  焦点态只用背景提示，所以编辑前后字形完全一致。

## 6. 踩过的坑

| 现象 | 原因 |
|---|---|
| 页面上出现一块浅色矩形边框 | `.hero` 的 padding 没清掉，贴图被挤在小盒子里 |
| `javac: 非法字符: '\ufeff'` | PowerShell 5.1 的 `-Encoding UTF8` 会写 BOM，Java 不认 |
| 某条 CSS 规则整段失效 | 内联样式时文件开头的 BOM 混在文档中间，把紧随其后的规则打断 |
| 手机上页面被拉成 360 宽 | `#stage` 在窄视口里被 flex 压缩，需要 `flex: 0 0 375px` |
| aapt2 打出的 assets 路径带反斜杠 | Windows 下子目录名写成 `assets/xxx\yyy`，Android 侧取不到，改成平铺文件名 + 拦截映射 |
